# Tela de Login PlotCell

Tela de login com efeito de vidro (glassmorphism), feita para estudar HTML e CSS.

**Ver ao vivo:** https://Dev-Erick-Rodrigo.github.io/login-plotcell/

## O que tem na página

- Formulário com campos de e-mail e senha, com ícones
- Opção "Lembrar senha" e link "Esqueci a senha"
- Botão de login com efeito de hover
- Link para cadastro
- Fundo com imagem e `backdrop-filter: blur`
- Responsivo: se adapta a telas pequenas

## Tecnologias

- HTML5
- CSS3
- Google Fonts (Poppins)
- Boxicons

## Como rodar

Baixe o repositório e abra o arquivo `index.html` no navegador. Não precisa instalar nada.

> Este projeto é só o visual do formulário. Ainda não envia nem valida dados.
